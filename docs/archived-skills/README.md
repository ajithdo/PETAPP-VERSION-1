# Archived design-style skills

These skills competed with Impeccable and frontend-design, the two design-style skills this project keeps. Claude Code only loads skills from `.claude/skills/`, so the ones here are kept for reference and no longer load.

To bring one back, move its folder back into `.claude/skills/` (for example `git mv docs/archived-skills/minimalist-ui .claude/skills/minimalist-ui`).
